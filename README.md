# 🚀 arena-bridge

Локальный OpenAI-совместимый API-мост к веб-интерфейсу **arena.ai** (бывший LMSYS Chatbot Arena) для личного использования на Android в **Termux** (без root) и на ПК.

Позволяет подключать любые стандартные клиенты (Chatbox, NextChat, OpenWebUI, боты и др.) к моделям arena.ai через стандартный OpenAI API с поддержкой стриминга (SSE).

---

## 🏗️ Архитектура

```
+------------------------------------+
|  Любой OpenAI-клиент               |
|  (Chatbox, NextChat, Python SDK)   |
+-----------------+------------------+
                  |  HTTP /v1/chat/completions
                  v
+------------------------------------+
|  Сервер Python (Termux / PC)       |
|  FastAPI + WebSocket Bridge        |
|  (http://127.0.0.1:8000)           |
+-----------------+------------------+
                  |  WebSocket ws://127.0.0.1:8000/ws
                  v
+------------------------------------+
|  Браузер (Firefox / Kiwi)          |
|  Вкладка arena.ai/text/direct      |
|  Userscript (Tampermonkey)         |
|  (Куки, сессия, grecaptcha v3)     |
+-----------------+------------------+
                  |  fetch()
                  v
+------------------------------------+
|  arena.ai Next.js API              |
|  (create-evaluation / delete)      |
+------------------------------------+
```

### Принцип работы:
1. Каждый запрос клиента создаёт **новый чат** на arena.ai.
2. Userscript в контексте авторизованной вкладки отправляет запрос с валидными куками и токеном reCAPTCHA.
3. Ответ стримится клиенту в формате SSE (`data: {...}`).
4. Сразу после получения ответа чат **гарантированно удаляется** через Server Action `deleteEvaluationSession` (или сохраняется в очередь `failed_deletions.json` для повторного удаления при обрыве).

## 📱 Быстрый старт на Android (Termux)

### Шаг 1. Установка сервера в Termux

1. Установите [Termux с F-Droid](https://f-droid.org/packages/com.termux/) (версия из Google Play устарела и не работает).
2. Запустите Termux и склонируйте / скопируйте проект:
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ> arena-bridge
   cd arena-bridge
   ```
3. Запустите скрипт автоматической установки:
   ```bash
   chmod +x install_termux.sh
   ./install_termux.sh
   ```
   Скрипт установит Python, создаст виртуальное окружение `venv`, установит зависимости и подготовит `config.yaml`.

4. Запустите сервер:
   ```bash
   ./run.sh
   ```
   *Скрипт `run.sh` автоматически активирует `termux-wake-lock`, предотвращая засыпание процесса в фоне.*

При первом запуске сервер сгенерирует уникальный случайный API-ключ вида `sk-arena-...` и выведет его в консоль.

---

### Шаг 2. Настройка браузера на Android

Для работы моста потребуется браузер с поддержкой расширений для Userscript:

#### Вариант А: Firefox для Android
1. Установите **Firefox** (или **Firefox Nightly**).
2. Откройте Меню -> **Дополнения** (Add-ons).
3. Установите **Tampermonkey** или **Violentmonkey**.

#### Вариант Б: Kiwi Browser
1. Установите **Kiwi Browser** из Google Play / GitHub (полная поддержка Chrome Extensions).
2. Откройте Chrome Web Store и установите **Tampermonkey**.

---

### Шаг 3. Установка Userscript (в 1 клик)

1. Убедитесь, что сервер запущен (`./run.sh`).
2. В браузере (Firefox или Kiwi) перейдите по адресу:
   ```text
   http://127.0.0.1:8000/userscript.user.js
   ```
3. Расширение (Tampermonkey / Violentmonkey) автоматически предложит установить скрипт **arena-bridge**. Нажмите кнопку **«Установить»** (Install).
4. Откройте в браузере страницу:
   ```text
   https://arena.ai/text/direct
   ```
5. Войдите в свой аккаунт на `arena.ai`.
6. В правом нижнем углу страницы появится виджет моста:
   `🟢 Bridge: Ready` — означает, что Userscript успешно связался с сервером!

> 💡 **Как держать вкладку активной в фоне на Android**:
> - Отключите оптимизацию батареи для **Termux** и для выбранного **браузера**: *Настройки Android → Приложения → Termux / Firefox → Батарея → Не ограничивать (Unrestricted)*.
> - Не закрывайте вкладку `arena.ai/text/direct`, оставляйте её открытой. Сервер отправляет периодический heartbeat (ping каждые 12 секунд), чтобы предотвратить разрыв сокета.

## 💻 Запуск на ПК (Linux / macOS / Windows)

1. Клонируйте репозиторий и установите зависимости:
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # На Windows: venv\Scripts\activate
   pip install -r requirements.txt
   cp config.example.yaml config.yaml
   ```
2. Запустите сервер:
   ```bash
   python3 -m server
   ```
3. В любом браузере с Tampermonkey откройте `http://127.0.0.1:8000/userscript.user.js` для установки скрипта.
4. Откройте вкладку `https://arena.ai/text/direct` и залогиньтесь.

## ⚙️ Конфигурация (`config.yaml`)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `host` | `"127.0.0.1"` | IP адрес сервера (`0.0.0.0` открывает доступ в сеть с предупреждением) |
| `port` | `8000` | Порт локального сервера |
| `api_key` | `""` | Секретный ключ (`Authorization: Bearer <key>`). При пустом значении генерируется автоматически |
| `max_concurrency` | `1` | Макс. параллельных запросов к arena.ai |
| `request_timeout` | `180` | Таймаут ожидания ответа (в секундах) |
| `min_request_interval`| `1.5` | Пауза между запросами (в сек) для предотвращения rate-limit (429) |
| `delete_chats` | `true` | Автоматически удалять чаты после ответа |
| `prompt_format` | `"role_blocks"` | Формат склейки истории: `role_blocks`, `plain`, `chatml` |
| `models_override` | `[]` | Ручное переопределение / добавление списка моделей |
| `log_level` | `"INFO"` | Уровень логов (в режиме `INFO` сообщения и ключи скрыты) |

## 📡 Использование в клиентах

В любом OpenAI-совместимом клиенте (Chatbox, NextChat, LobeChat, OpenWebUI, Cline, Roo Code, Continue) настройте:

- **API Base URL**: `http://127.0.0.1:8000/v1`
- **API Key**: Ваш ключ из `config.yaml`
- **Model**: Любое имя модели из списка arena.ai (например, `gemini-3.1-pro-preview`, `gpt-5.5-instant`, `gemini-3.6-flash`, `grok-4.20-beta-0309-reasoning`)

## 🧪 Тестирование

### 1. Автоматические модульные тесты
```bash
python3 -m pytest -v
```
Все 22 теста проверяют:
- Форматирование промптов и склейку ролей;
- Валидацию модальностей (отклонение картинок с кодом ошибки);
- Формирование SSE-чанков OpenAI (включая reasoning);
- Аутентификацию (401 при неверном ключе);
- Ошибку 503 при отсутствии Userscript;
- Ошибку 404 при неизвестной модели;
- Полноценный сквозной цикл со стримингом через тестовый мост.

### 2. Тестовый клиент запросов
```bash
# Проверка здоровья
python3 scripts/test_client.py --only-health

# Проверка стриминга и не-стриминга
python3 scripts/test_client.py --model "gemini-3.1-pro-preview" --prompt "Привет! Расскажи коротко о себе."
```

## 🛡️ Безопасность и удаление чатов

1. **Защита от потери данных**: мост отслеживает и удаляет **исключительно те сессии, которые создал он сам**. Чужие диалоги никогда не затрагиваются.
2. **Очередь недоудалённых чатов**: если во время запроса оборвалась связь или упал браузер, ID чата сохраняется в `failed_deletions.json` и при следующем подключении Userscript автоматически удаляется.
3. **Безопасность логов**: промпты пользователей и секретные API-ключи не записываются в консоль/логи.
