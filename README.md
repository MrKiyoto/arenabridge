# ⚔️ arena-bridge — Халявный доступ к топ нейросетям через Arena.ai

Мост, который превращает веб-версию **arena.ai** (бывший Chatbot Arena / LMSYS) в полноценный **локальный OpenAI API**. 

Зачем это нужно? Чтобы бесплатно гонять топовые модели (Claude 3.7 / 3.5 Sonnet, Gemini 2.0 / 1.5 Pro, GPT-4o, o3, Grok и др.) в **SillyTavern**, Chatbox, NextChat и любых других клиентах прямо со смартфона (через Termux) или с компьютера.

---

## 💡 Как это вообще работает?

Всё просто:
1. На телефоне или ПК крутится лёгкий локальный сервер на Python (`http://127.0.0.1:8000`).
2. В браузере (на вкладке `arena.ai/text/direct`) висит юзерскрипт (через Tampermonkey).
3. Сервер и вкладка общаются между собой по WebSocket.
4. Когда вы отправляете сообщение из SillyTavern, сервер передаёт его юзерскрипту, тот делает запрос от лица вашего браузера на arena.ai со всеми вашими куками, забирает ответ и стримит обратно в таверну.
5. После каждого ответа чат на arena.ai **автоматически удаляется**, чтобы не засорять историю.

## 📱 Инструкция для Android (Termux + Браузер)

Идеальный сетап, чтобы ролеплеить прямо с телефона.

### Шаг 1. Ставим Termux
> ⚠️ **Важно:** Версия из Google Play давно мертва и не обновляется! Качайте **только** с [F-Droid](https://f-droid.org/packages/com.termux/).

Запустите Termux и вставьте команду для установки (скачает репозиторий и настроит зависимости):

```bash
pkg update -y && pkg install -y git python
git clone https://github.com/MrKiyoto/idontknow.git arena-bridge
cd arena-bridge
chmod +x install_termux.sh run.sh
./install_termux.sh
```

После завершения установки запускаем мост:
```bash
./run.sh
```

В консоли появится ваш сгенерированный API-ключ вида `sk-arena-...` и адрес сервера `http://127.0.0.1:8000`. Не закрывайте Termux!

---

### Шаг 2. Настраиваем браузер (Kiwi Browser или Firefox)

Браузер нужен с поддержкой расширений:
- Рекомендую **Kiwi Browser** (ставится из Google Play, есть поддержка расширений из Chrome Web Store).
- Либо **Firefox Nightly** / обычный Firefox с включёнными дополнениями.

1. Установите расширение **Tampermonkey** (или Violentmonkey) в браузер.
2. Откройте в браузере ссылку:
   ```
   http://127.0.0.1:8000/userscript.user.js
   ```
3. Tampermonkey сам перехватит скрипт и покажет окно установки. Нажмите кнопку **Установить (Install)**.
4. Откройте вкладку:
   ```
   https://arena.ai/text/direct
   ```
5. Залогиньтесь на сайте (или останьтесь гостем). В правом нижнем углу страницы появится плашка:
   `🟢 Bridge: Ready`
   Это значит, что скрипт подцепился к серверу и готов к работе!

---

### Шаг 3. Подключаем SillyTavern

1. В SillyTavern открываем настройки API (иконка вилки/штекера вверху):
   - **API:** `Chat Completion`
   - **Chat Completion Source:** `OpenAI` (или Custom / Reverse Proxy)
   - **Custom Endpoint / Server URL:** `http://127.0.0.1:8000/v1`
   - **API Key:** ваш ключ из консоли Termux (или скопируйте из файла `config.yaml`)
2. Нажмите **Connect** или выберите модель из списка вручную (например, `claude-3-7-sonnet`, `gemini-2.0-flash`, `gpt-4o` и т.д.).
3. Всё готово! Можно писать персонажу.

## 🔒 Что делать, если вылезла капча?

Arena.ai защищена Cloudflare и reCAPTCHA Enterprise. Иногда (особенно на мощных моделях) сайт может выдать проверку.

Мы это предусмотрели:
1. Если сервер арены запросит проверку, в виджете появится статус: `🔒 CAPTCHA required...`
2. Переключитесь на открытую вкладку `arena.ai` в браузере.
3. Поверх страницы появится окошко с чекбоксом **«Я не робот»**. Поставьте галочку (или решите картинки, если попросит).
4. Как только капча решится, окно закроется, и ответ сам пойдёт в SillyTavern! Ничего перезапускать не нужно.

## 💻 Установка на ПК (Windows / Linux / macOS)

1. Убедитесь, что установлен Python 3.10+.
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/MrKiyoto/idontknow.git arena-bridge
   cd arena-bridge
   python -m venv venv
   ```
   - Windows: `venv\Scripts\activate`
   - Linux/Mac: `source venv/bin/activate`
3. Установите библиотеки:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите:
   ```bash
   python -m server
   ```
5. В браузере (Chrome / Firefox / Edge с Tampermonkey) откройте `http://127.0.0.1:8000/userscript.user.js` и установите скрипт.
6. Откройте `https://arena.ai/text/direct` и оставьте вкладку открытой.

## ⚙️ Настройки (`config.yaml`)

Файл создаётся автоматически при первом запуске:

```yaml
host: "127.0.0.1"        # Адрес (0.0.0.0 если хотите подключаться с других устройств в локалке)
port: 8000               # Порт
api_key: ""              # Ваш API ключ (если пусто — сгенерируется сам)
max_concurrency: 1       # Запросов одновременно (лучше оставить 1)
request_timeout: 180     # Таймаут ответа в секундах
min_request_interval: 1.5 # Пауза между запросами (чтобы не ловить 429)
delete_chats: true       # Автоудаление созданных чатов после ответа
prompt_format: "role_blocks" # Формат промпта (role_blocks / plain / chatml)
```

## ❓ FAQ и частые вопросы

**Q: Вкладка arena.ai в браузере должна быть открыта всегда?**  
Да, браузер должен быть запущен с открытой вкладкой `https://arena.ai/text/direct`, так как запросы к нейросетям идут через неё.

**Q: Сколько сообщений можно отправлять?**  
На arena.ai есть дневной лимит расходов (daily spend limit). На тяжёлых моделях (Claude 3.7 Sonnet) он расходуется быстрее, на лёгких (Gemini Flash) — намного дольше. Если поймали лимит — достаточно либо подождать сброса (по UTC), либо просто почистить куки сайта / сменить аккаунт на арене.

**Q: Поддерживается ли стриминг (печатание текста в реальном времени)?**  
Да, полный честный SSE-стриминг (включая передачу блоков reasoning / thinking для рассуждающих моделей).
