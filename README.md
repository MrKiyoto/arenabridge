## 💡 Как это вообще работает?

Всё просто:
1. На телефоне или ПК крутится лёгкий локальный сервер на Python (`http://127.0.0.1:8000`).
2. В браузере (на вкладке `arena.ai/text/direct`) висит юзерскрипт (через Tampermonkey).
3. Сервер и вкладка общаются между собой по WebSocket.
4. Когда вы отправляете сообщение из SillyTavern, сервер передаёт его юзерскрипту, тот делает запрос от лица вашего браузера на arena.ai со всеми вашими куками, забирает ответ и стримит обратно в таверну.
5. После каждого ответа чат на arena.ai **автоматически удаляется**, чтобы не засорять историю.

## 📱 Инструкция для Android (Termux + Браузер)

### Шаг 1. Ставим Termux
> ⚠️ **Важно:** Версия из Google Play давно мертва и не обновляется! Качайте **только** с [F-Droid](https://f-droid.org/packages/com.termux/).

Запустите Termux и вставьте команду для установки (скачает репозиторий и настроит зависимости):

```bash
pkg update -y && pkg install -y git python
git clone https://github.com/MrKiyoto/idontknow.git arena-bridge
cd arena-bridge
chmod +x install_termux.sh run.sh
./install_termux.sh
```

После завершения установки запускаем мост:
```bash
./run.sh
```

В консоли появится ваш сгенерированный API-ключ вида `sk-arena-...` и адрес сервера `http://127.0.0.1:8000`. Не закрывайте Termux!

---

### Шаг 2. Настраиваем браузер (Kiwi Browser или Firefox)

Браузер нужен с поддержкой расширений:
- Рекомендую **Kiwi Browser** (ставится из Google Play, есть поддержка расширений из Chrome Web Store).
- Либо обычный Firefox с включёнными дополнениями.

1. Установите расширение **Tampermonkey** (или Violentmonkey) в браузер.
2. Откройте в браузере ссылку:
   ```
   http://127.0.0.1:8000/userscript.user.js
   ```
3. Tampermonkey сам перехватит скрипт и покажет окно установки. Нажмите кнопку **Установить (Install)**.
4. Откройте вкладку:
   ```
   https://arena.ai/text/direct
   ```
5. Залогиньтесь на сайте (или останьтесь гостем). В правом нижнем углу страницы появится плашка:
   `🟢 Bridge: Ready`
   Это значит, что скрипт подцепился к серверу и готов к работе!

---

### Шаг 3. Подключаем SillyTavern

1. В SillyTavern открываем настройки API (иконка вилки/штекера вверху):
   - **API:** `Chat Completion`
   - **Chat Completion Source:** `OpenAI` (или Custom / Reverse Proxy)
   - **Custom Endpoint / Server URL:** `http://127.0.0.1:8000/v1`
   - **API Key:** ваш ключ из консоли Termux (или скопируйте из файла `config.yaml`)
2. Нажмите **Connect** или выберите модель из списка вручную (например, `deepseek-v4-flash-max`, `gemini-3.1-pro-preview`, `glm-5.1` и т.д.).
3. Всё готово!

## ВАЖНЫЙ МОМЕНТ

Что бы сообщение пришло в SillyTavern (или в любое другое приложение) нужно будет пройти капчу на сайте

Поэтому сделайте это:
1. Переключитесь на открытую вкладку `arena.ai` в браузере.
2. Поверх страницы появится окошко с чекбоксом **«Я не робот»**. Поставьте галочку (или решите картинки, если попросит).
3. Как только капча решится, окно закроется, и ответ сам пойдёт в SillyTavern!

## ⚙️ Настройки (`config.yaml`)

Файл создаётся автоматически при первом запуске:

```yaml
host: "127.0.0.1"        # Адрес (0.0.0.0 если хотите подключаться с других устройств в локалке)
port: 8000               # Порт
api_key: ""              # Ваш API ключ (если пусто — сгенерируется сам)
max_concurrency: 1       # Запросов одновременно (лучше оставить 1)
request_timeout: 180     # Таймаут ответа в секундах
min_request_interval: 1.5 # Пауза между запросами (чтобы не ловить 429)
delete_chats: true       # Автоудаление созданных чатов после ответа
prompt_format: "role_blocks" # Формат промпта (role_blocks / plain / chatml)
```
